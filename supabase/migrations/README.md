# ترحيلات Mini ERP

يوجد حالياً 8 ملفات SQL مرتبة رقمياً. الملفات `01`–`07` تنشئ جداول الأساس البالغ عددها 74؛ الملف `08` يضيف رمز الدور، أذونات القراءة، حدود المستأجر المستندة إلى ادعاء JWT، إخفاء حقول التكلفة، ومنع تعديل بعض سجلات الدفتر.

التطبيق مبني لـ Supabase لأن الجداول والصلاحيات تعتمد على `auth.users` و`auth.uid()` و`auth.jwt()` وأدوار Supabase. طبّق الملفات عبر `supabase db reset` على قاعدة محلية مؤقتة، أو بواسطة `scripts/apply_migrations_local.ps1` بعد تشغيل Supabase.

## قيود النسخة الحالية

- لا توجد بعد عمليات RPC كاملة لاستلام الشحنات، شحن الطلب، معالجة المرتجعات، حساب WAC، أو مطابقة التسويات.
- سياسة القراءة حسب الصلاحيات موجودة، بينما كتابة جداول الأعمال عبر `authenticated` ممنوعة حالياً حتى توجد مسارات خادمية محددة لكل سير عمل.
- دعم الوصول المؤقت، إدارة الدعوات، وعزل المستودعات لم يكتمل.
- هدف المشروع PostgreSQL 16، لكن Supabase CLI الذي فُحص لا يشغل محلياً إلا 15 أو 17. نجح التحقق الحالي على 17، وليس 16.

لا تعتبر نجاح bootstrap والاختبارات الستة اعتماداً إنتاجياً.
