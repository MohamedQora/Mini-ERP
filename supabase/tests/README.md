# مجموعات اختبار SQL

شغّل الاختبارات على قاعدة Supabase محلية مؤقتة فقط. كل ملف يبدأ معاملة ويتراجع عن بياناته. على Windows استخدم `./scripts/run_tests_local.ps1`؛ يتوقف السكربت عند أول خطأ.

| الملف | التغطية | الحد المعروف |
|---|---|---|
| `01_tenant_isolation_tests.sql` | عزل الصفوف ومفتاح المنتج المركب ومنع تجاوز محدد المستأجر | اختبار جلسة واحدة |
| `02_inventory_concurrency_tests.sql` | استبعاد التالف، الحجز الذري، إعادة المحاولة ومنع الحجز الزائد | لا ينشئ جلستين متنافستين |
| `03_business_logic_and_finance_tests.sql` | استقلال حالات الطلب/الدفع/التنفيذ وقيود المبالغ والمراجع | لا يختبر دورة مالية كاملة |
| `04_append_only_and_audit_tests.sql` | منع تعديل دفاتر المخزون والتدقيق وسجل الربح وتسلسل أرقام الطلبات | تغطية جزئية لسجلات الدفتر |
| `05_security_rls_hardening_tests.sql` | تفعيل RLS، امتيازات الحقول الحساسة وامتياز RPC | تحقق كتالوج |
| `06_runtime_rls_and_privilege_tests.sql` | قراءة الدور `authenticated`، عزل المستأجر ومنع الكتابة/RPC | لا يغطي مصفوفة أدوار ومستودعات كاملة |

نجحت الملفات الستة على Supabase محلي بإصدار PostgreSQL 17. لا يعني ذلك أن اختبارات السباق أو التشغيل الإنتاجي اجتازت.
