# ملاحظات الواجهة

## التطبيق المقصود

`frontend/` هو تطبيق Next.js الموصول بمكتبات Supabase وطبقة المصادقة. `my-next-app/` مجلد قالب منفصل لا يستخدم قاعدة ERP.

## الموجود

- تسجيل دخول بالبريد وكلمة المرور، تجديد جلسة، تسجيل خروج، وحماية مسارات عبر `src/proxy.ts`.
- اختيار المستأجر وتبديله عبر route خادمي يتحقق من العضوية النشطة ويحدّث `app_metadata.tenant_id`.
- واجهة عربية/إنجليزية وRTL، غلاف وحدات مشترك، ومكونات UI.
- دعم متغير `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` مع fallback للمتغير القديم anon.
- صفحات المنتجات والطلبات والمخزون وباقي الوحدات لا تزال تمهيدية؛ لا تعرض CRUD أو سير عمل مكتمل.

## تكامل المخطط

- أسماء حقول tenant في قاعدة البيانات `base_currency_code` و`default_timezone`؛ تحولها طبقة الجلسة إلى حقول واجهة داخلية.
- ملف المستخدم يستخدم `user_id` و`display_name`، وليس `id` و`full_name`.
- الدور يستخدم `roles.code` و`roles.name` بعد الترحيل 08.
- RLS يقرأ tenant من JWT عبر `public.current_tenant_id()`؛ تبديل المستأجر يجب أن يتم على الخادم.
- route تبديل المستأجر يستخدم `SUPABASE_SERVICE_ROLE_KEY`؛ يجب أن يبقى متغيراً خادمياً ولا يرسل للمتصفح.

## التحقق والحدود

`npm run typecheck` و`npm run build` هما فحصا الواجهة. لم يُختبر تسجيل الدخول ضد مشروع سحابي، ولا يجوز توجيه `.env.local` إلى السحابة عند إجراء اختبارات كتابة محلية. القيم المحلية النموذجية في `.env.example`.
