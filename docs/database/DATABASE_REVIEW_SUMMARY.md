# ملخص مراجعة قاعدة Mini ERP

## المرجع المعماري

المخطط المرجعي المحدد في `docs/mini_erp_master_blueprint.md` هو PostgreSQL/Supabase متعدد المستأجرين، 74 جدولاً، RLS، RBAC، مفاتيح مركبة، دفتر مخزون، وحالات منفصلة للطلب والدفع والتنفيذ.

## الموجود فعلياً

- 8 ملفات ترحيل حالية؛ 74 جدولاً في الأساس.
- RLS مفعّل على الجداول المملوكة للمستأجر. الترحيل 08 يربط القراءة بمطالبة المستأجر في JWT وصلاحية الدور.
- حجز مخزون ذري بالتتابع مع قفل صف وإعادة محاولة idempotent، ودفتر غير قابل للتعديل لجداول مختارة.
- واجهة Next.js في `frontend/`؛ غالبية وحدات ERP تمهيدية ولا تنفذ CRUD أو مسارات الأعمال بعد.

## التحقق الفعلي

اجتاز bootstrap وملفات SQL الستة على Supabase محلي باستخدام PostgreSQL 17. اجتاز `typecheck` و`build` للواجهة. لم يُختبر PostgreSQL 16 ولا سباق جلسات حقيقي ولا تكامل سحابي.

## الفجوة الرئيسية

المخطط والواجهة لا يشكلان بعد ERP كاملاً: لا توجد عمليات كاملة لاستلام المورد وWAC، خصم المخزون عند pickup، المرتجعات، التسوية المالية، أو الأرباح. وبعض المساعدات المذكورة في الوثائق التصميمية لا توجد في الترحيلات الحالية. انظر `NEXT_STAGE_READINESS.md`.
