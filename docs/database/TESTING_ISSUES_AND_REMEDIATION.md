# سجل مشكلات الفحص والمعالجة

| المشكلة | النتيجة | الحالة |
|---|---|---|
| الوثائق تصف 15 ترحيلاً بينما الموجود 7 | جرى تصحيح وثائق الحالة إلى 7 أساسية + 08 | معالجة |
| RLS يعتمد GUC قابل للتغيير وسياسة العضو واسعة | استبدل بحد المستأجر من JWT وقراءة حسب الصلاحيات | اختبر محلياً على PostgreSQL 17 |
| حقل الضرر لا يُستبعد من `available` | أضيفت معادلة `on_hand - reserved - damaged` مع قيد جمع القيم | اختبر ضمن المجموعة 02 |
| حجز المخزون لا يحمي إعادة المحاولة | قفل صف المخزون ثم جعل تكرار نفس الحجز idempotent | اختبر تسلسلياً فقط |
| دفاتر مختارة قابلة للتعديل/الحذف | أضيفت مشغلات منع على دفاتر المخزون والتدقيق والحالات والتكلفة | اختبر ضمن المجموعة 04 |
| صفحات الواجهة تطلب أعمدة غير موجودة ومفتاحاً قديماً | طوبقت الاستعلامات على أسماء المخطط ودعم publishable key | typecheck/build مطلوبان بعد التعديل النهائي |
| اختبارات SQL القديمة لا تطابق الجداول والدوال | أعيدت كتابة المجموعات الست على المخطط الفعلي | اجتازت على PostgreSQL 17 |
| Supabase CLI المحلي يرفض PostgreSQL 16 | جرى اختبار مؤقت على PostgreSQL 17 دون تعديل إعداد الهدف | تحقق 16 ما زال مفتوحاً |

لم يُختبر سباق متعدد الاتصالات. لا تدعي هذه القائمة اكتمال ERP أو الجاهزية للإنتاج.
