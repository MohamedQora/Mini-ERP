# اختبار قاعدة البيانات

تتكون الحزمة الحالية من ست مجموعات SQL موضحة في `supabase/tests/README.md`. تستخدم fixtures قصيرة داخل معاملات وتتراجع عنها. على Windows شغّل `./scripts/run_tests_local.ps1` من جذر المشروع؛ يرفض السكربت أي قاعدة لا تستخدم `localhost` أو `127.0.0.1:54322`.

## نتيجة آخر تشغيل

نجحت المجموعات الست بعد bootstrap نظيف على Supabase محلي بإصدار PostgreSQL 17. الهدف المعماري PostgreSQL 16، لكن CLI المتاح لا يدعم تشغيل هذا الإصدار محلياً.

## حدود التحقق

لا تمثل الاختبارات مصفوفة RBAC كاملة، ولا تختبر مستودعات متعددة أو اتصالات متزامنة أو تسوية مالية كاملة أو كل وظائف Supabase Auth. نجاحها ليس موافقة إنتاجية. قائمة العمل المتبقية في `NEXT_STAGE_READINESS.md`.
