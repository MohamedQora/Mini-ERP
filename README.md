# Mini ERP

مشروع ERP متعدد المستأجرين لعلامات الملابس، يستهدف Supabase وPostgreSQL. يحتوي المخطط الحالي على 74 جدولاً عبر 7 ملفات ترحيل أساسية وترحيل أمني أمامي واحد، مع واجهة Next.js في `frontend/` وست مجموعات SQL.

## الحالة الفعلية

- اجتاز `npm run typecheck` و`npm run build` في مجلد `frontend/`.
- طُبقت الترحيلات الثمانية واجتازت مجموعات SQL الست على Supabase محلي بإصدار PostgreSQL 17.
- خادم نسخة البناء يعمل محلياً على `http://127.0.0.1:3001`؛ صفحة الدخول تعيد HTTP 200 ومسار تبديل المستأجر يرفض المستخدم غير المصادق بـ 401.
- إعداد المشروع يستهدف PostgreSQL 16، لكن إصدار Supabase CLI المتاح حالياً لا يشغّل 16 محلياً؛ لم يُثبت ذلك الإصدار على قاعدة 16.
- وحدات الواجهة ما زالت هياكل وصفحات تمهيدية؛ لم تُنفذ بعد تدفقات ERP الكاملة مثل الشراء والتسوية والشحن.
- لم تُنفذ اختبارات جلسات متزامنة حقيقية، ولم يُجر اتصال أو تغيير على مشروع Supabase السحابي.
